# Horizon: локальный запуск, обновления вручную

Это изменённые исходники, а не готовый EXE. Заменить установленную программу этим ZIP нельзя: сначала нужна сборка.

## Что изменено
- Microsoft-вход необязателен для локального запуска через GUI, CLI и встроенный MCP.
- Локальные ники работают без Microsoft-аккаунта, в том числе после выхода из аккаунта.
- Нет принудительного окна входа на старте; вход сохранён в настройках как опция.
- Без аккаунта доступна подготовка из собственной локальной установки Minecraft.
- Выключены автоматические проверки обновлений при старте и по таймеру.
- Выключена автоматическая установка новых версий, даже если старый settings.json включал её; переключатель заблокирован.
- Самообновление лаунчера заблокировано, чтобы исходная версия не затёрла изменения.
- Ручная проверка обновлений только показывает доступные версии. Установка Horizon — вручную через Versions или CLI.
- Nightly больше не обновляется при проверках/старте; установка возможна при явном включении Nightly.
- Каталог доступных версий и обычные ссылки по-прежнему загружаются; это не полностью автономная сборка.

## Ограничения
Архив не содержит игровых ресурсов Minecraft. Существующие проверки настоящей онлайн-сессии и права на скачивание от имени аккаунта сохранены. Серверы с online-mode=true требуют подходящий Microsoft-аккаунт; локальный режим не обходит серверную проверку.

## Сборка
Установите Rust и системные зависимости GPUI для своей ОС, описанные в launcher/README.md. В каталоге launcher выполните:

```sh
cargo build --release
```

Бинарник: launcher/target/release/horizon-launcher (на Windows — horizon-launcher.exe).

Для локального ника:

```sh
horizon-launcher account offline Builder_1
horizon-launcher play
```

В GUI: Settings → локальные имена → добавить ник; игровые ресурсы подготовить из локальной установки.

## Проверки
Регрессионные тесты обновлены для необязательного входа и отключённых автообновлений:

```sh
cd launcher
cargo test --lib
cargo test --test owner_gate
```

В среде подготовки отсутствует Rust/Cargo: сборка и Rust-тесты не запускались. Отдельный QA_REPORT.txt фиксирует выполненные проверки. Исходные лицензии и уведомления сохранены.
